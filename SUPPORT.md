# Support

## Usage help

Check the [README](README.md) and existing
[issues](https://github.com/ScotsGamez/create-schematic-viewer/issues) first.
If the problem is not already covered, open a bug report or feature request
using the repository's issue forms.

For a useful bug report, include:

- Operating system, Node.js version, and Python version.
- The exact command and concise reproduction steps.
- Expected and actual behavior.
- Relevant sanitized logs.
- Whether the issue reproduces with a synthetic or redistributable fixture.

Do not upload schematics, mod JARs, resource packs, screenshots, or logs unless
you have permission to share them. Remove secrets, personal information,
private server details, and player data.

## Security issues

Follow [SECURITY.md](SECURITY.md). Do not report vulnerabilities publicly.

## Project scope

Support covers Create Schematic Viewer itself. Minecraft installation, modpack
support, third-party mod behavior, and Create gameplay are outside the project's
support scope unless a reproducible viewer defect is involved.
